本ドキュメントは、Amazon KDP出版用の電子書籍（Kindle）表紙、およびペーパーバック（紙書籍）用見開き表紙PDFの幾何学仕様、寸法計算モデル、解像度要件、およびPDF変換パイプラインに関する技術仕様書です。

## 2. ペーパーバック見開き幾何学仕様（Geometry Specification）

ペーパーバックの表紙は、表表紙・背表紙・裏表紙が一体となった単一の見開きPDFを入稿する必要があります。
Amazon KDPの印刷機が物理裁断を行うため、以下の幾何学的寸法計算モデルに厳密に準拠しなければなりません。

```
|<--------------------------------- 全体幅 (Overall Width) --------------------------------->|
+-------------------+--------------------+------------------+--------------------+------------+
| 裁ち落とし (左)   | 裏表紙 (Back)      | 背表紙 (Spine)   | 表表紙 (Front)     | 裁ち落とし |
| 0.125 in (3.2 mm) | [Trim Width]       | [Spine Width]    | [Trim Width]       | 0.125 in   |
|                   |                    |                  |                    | (3.2 mm)   |
|                   |                    |                  |                    |            |
|                   |                    |                  |                    |            |
|                   |                    |                  |                    |            |
|                   |                    |                  |                    |            |
|                   |          [Barcode] |                  |                    |            |
+-------------------+--------------------+------------------+--------------------+------------+
|<--------------------------- 全体高さ: Trim Height + 0.25 in (裁ち落とし上下) -------------->|
```

### 2.1 寸法計算モデル（数式仕様）

書籍の判型（幅 $W_{\text{trim}}$、高さ $H_{\text{trim}}$）はユーザーが決定するパラメータです。どのような判型を選択した場合でも、以下の計算式により見開き全体の必要寸法が算出されます。

- **不変の印刷マージン仕様**:
  - **裁ち落とし（Bleed）**: 上下左右の各外側に `0.125 インチ`（`3.175 mm`）が必須。
- **全体高さ ($H_{\text{overall}}$)**:
  $$H_{\text{overall}} = H_{\text{trim}} + (0.125 \times 2) = H_{\text{trim}} + 0.25 \text{ インチ}$$
- **背表紙幅 ($W_{\text{spine}}$)**:
  本文の総ページ数（`book/dist/contents.pdf`）と用紙の種類に基づき算出：
  - 白用紙（標準）: $\text{ページ数} \times 0.002252 \text{ インチ}$
  - クリーム用紙: $\text{ページ数} \times 0.0025 \text{ インチ}$
- **全体幅 ($W_{\text{overall}}$)**:
  $$W_{\text{overall}} = 0.125 + W_{\text{trim}} + W_{\text{spine}} + W_{\text{trim}} + 0.125 \text{ インチ}$$

### 2.2 本テンプレート同梱サンプルの初期設定値（A5判の例）

本テンプレートの初期サンプル書籍（`metadata-pdf.yaml`）では、日本の標準的な書籍判型である **A5判** を採用しています。

- **サンプル判型**: A5判（$W_{\text{trim}} = 5.827 \text{ in} / 148 \text{ mm}$、$H_{\text{trim}} = 8.268 \text{ in} / 210 \text{ mm}$）
- **サンプル全体高さ**: $8.268 + 0.25 = 8.518 \text{ インチ } (216.36 \text{ mm})$
- **サンプル全体幅**: $0.25 + (5.827 \times 2) + W_{\text{spine}} = 11.904 \text{ インチ } + W_{\text{spine}}$

※ユーザーが判型を四六判（127×188mm）やB6判（128×182mm）等に変更した場合は、上記の計算式に基づき `metadata-pdf.yaml` の設定とKDP表紙テンプレートのダウンロード寸法を合わせて変更してください。

### 2.3 セーフゾーンとバーコード禁止領域
- **セーフゾーン（テキスト安全マージン）**: 仕上がり線から内側 `0.25 インチ`（`6.4 mm`）以内に重要なテキスト・ロゴを配置（裁断時のズレによる文字切れを防止）。
- **バーコード配置領域**: 裏表紙の右下（幅 2.0 インチ × 高さ 1.2 インチ）は、Amazon印刷機が自動的にISBNバーコードを合成するため、文字や重要なグラフィックの配置が禁止されています。


## 3. 入稿用PDF生成パイプライン仕様

KDPペーパーバックでは画像ファイル（PNG/JPEG）での入稿が拒否され、**ベクター化された正確な寸法のPDF**が要求されます。

### 3.1 ラスタ画像から完全同一寸法PDFへの変換メカニズム
画像編集ソフトから書き出された高解像度PNG（`cover_to_paperback.png`）から、ピクセルの寸法を1ポイントも狂わせずにPDF化するため、PythonのPillowライブラリを用いてDPIメタデータを強制固定します。

```sh
python -c "from PIL import Image; Image.open('book/cover/cover_to_paperback.png').convert('RGB').save('book/cover/cover_to_paperback.pdf', format='PDF', resolution=300.0)"
```

### 3.2 なぜ解像度 300.0 DPI 固定が必要か
- PDF内部の座標系はポイント単位（1 pt = 1/72 インチ）で記述されます。
- 解像度が `300.0 DPI` として正しく埋め込まれていない場合、PDFリーダーやKDPの自動検版システムがデフォルトの `72 DPI` で解釈し、寸法が約4.16倍に拡大されて入稿エラー（サイズ不一致）が発生します。
- 上記コマンドにより、ラスタピクセル数 $N$ に対して $\text{pt} = N \times \frac{72}{300}$ の正確なMediaBoxサイズがPDFヘッダーに書き込まれます。


## 4. 電子書籍（Kindle）用表紙仕様

| 項目 | 技術仕様 | 根拠・理由 |
|:---|:---|:---|
| **フォーマット** | JPEG (RGB, ベースライン) | Amazon KDPポータル推奨仕様 |
| **推奨ピクセル数** | 1,600 × 2,560 px (縦横比 1:1.6) | 高解像度Retina/Fire HD端末での鮮明な表示 |
| **最小ピクセル数** | 1,000 × 625 px | これ未満はKDP検版で警告 |
| **カラープロファイル** | sRGB | デジタルディスプレイ表示での色化け防止 |
| **ファイルサイズ** | 50 MB以下 | KDPアップロード上限 |
