# 表紙・装丁制作手順書 (book/cover/README.md)

> [!NOTE]
> 電子書籍と紙書籍（ペーパーバック）では、表紙に求められるデータ形式が根本から異なります。
> まず「何を用意すべきか」を確認し、紙書籍については本文ページ数を元にテンプレートをダウンロードして、機械的に入稿用PDFを生成します。
> 印刷寸法や背表紙幅の厳密な計算仕様については、[specification.md](./specification.md) を参照してください。


## 電子書籍と紙書籍の違い（まず決めること）

| 種別 | 必要な表紙データ | 作成のタイミング |
|:---|:---|:---|
| **電子書籍（Kindle本）** | **縦長の画像1枚**（JPEG） | いつでも作成可能（ページ数無関係） |
| **紙書籍（ペーパーバック）** | **表・背・裏が一体の見開きPDF** | **製本（Step 2）完了後**（ページ数で背表紙幅が決まるため） |

## 3-2. 表紙制作の作業手順

### 1. 電子書籍（Kindle本）の表紙（作業時間: 5分）

縦長の表紙画像を1枚用意するだけで完了です。

1. お好みのツール（Canva, Photoshop, 画像生成AI等）で表紙画像を作成します（推奨アスペクト比 1:1.6 / 例: 1600×2560px 等）。
2. 画像を以下の2か所へコピー・配置します：
   - `book/cover/cover.png`（EPUB内部埋め込み用）
   - `book/cover/cover_for_kdp.jpg`（KDPポータル登録用JPEG）


### 2. ペーパーバック（紙書籍）の表紙（作業手順）

紙書籍の表紙は、物理的な背表紙の厚みがあるため、「見開き1枚のPDF」として提出する必要があります。

#### Step 1: KDPから公式テンプレートをダウンロード
1. [KDP 表紙計算ツール](https://kdp.amazon.co.jp/cover-calculator) にアクセスします。
2. 以下の項目を入力して計算し、テンプレート（ZIP）をダウンロードします：
   - 製本タイプ: **ペーパーバック**
   - 本文の用紙: （出版内容に合わせる）
   - 読書の進行方向: （出版内容に合わせる）
   - 判型: （出版内容に合わせる）
   - ページ数: **総ページ数**
     - Step 2で生成した `book/dist/contents.pdf` のページ数
3. ダウンロードしたZIPを展開し、中に入っているPNG画像を `book/cover/` 配下に置きます。

#### Step 2: テンプレートに沿って画像をレイアウト
1. 画像編集ソフト（Canva, Photoshop, GIMP等）で、ダウンロードしたテンプレートPNGを下敷きとして開きます。
2. ガイド線に合わせて表紙・背表紙・裏表紙を配置します：
   - **右側**: 表表紙（タイトル、著者名）
   - **中央**: 背表紙（ページ数が少ない薄い本ならタイトルなしでもOK）
   - **左側**: 裏表紙（※右下のバーコード印字エリアに文字を置かないよう注意）
3. 編集が完了したら、テンプレートと完全に同じ解像度・寸法の1枚画像 **`book/cover/cover_to_paperback.png`** として書き出します。

#### Step 3: ワンライナーで入稿用PDFを生成
KDPペーパーバックでは画像入稿が不可のため、以下のPythonコマンドを実行して、寸法が1ピクセルも狂わない入稿用PDFを生成します：

```sh
# リポジトリルートで実行
python -c "from PIL import Image; Image.open('book/cover/cover_to_paperback.png').convert('RGB').save('book/cover/cover_to_paperback.pdf', format='PDF', resolution=300.0)"
```

※実行後、`book/cover/cover_to_paperback.pdf` が生成されます。
