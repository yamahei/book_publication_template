# 書籍コンテンツ・組版仕様 (book/specification.md)

本ドキュメントは、書籍コンテンツデータ（原稿Markdown、書誌メタデータYAML、組版スタイルシートCSS）のデータ仕様、スキーマ定義、および組版規則に関する技術仕様書です。


## 1. 原稿データ仕様 (`contents.md`)

書籍のマスター原稿となる `contents.md` は、CommonMarkに準拠したMarkdown形式で記述します。単一源泉からEPUBおよびLuaLaTeX組版へ自動変換されるため、以下の構文規則を定義しています。

### 1.1 見出し階層規則

| 記法 | 見出しレベル | 組版上の役割 | EPUBでの挙動 | PDF (LuaLaTeX)での挙動 |
|:---|:---|:---|:---|:---|
| `# タイトル` | レベル1 (H1) | **章（Chapter）** | 自動改ページ（改丁） | 自動改ページ（**左ページ起こし/偶数ページ**）、大見出し組版 |
| `## タイトル` | レベル2 (H2) | **節（Section）** | 目次（TOC）に反映 | 目次（TOC）に反映、節見出し組版 |
| `### タイトル` | レベル3 (H3) | **項（Subsection）**| 本文インライン | 小見出し組版（目次非掲載） |

- **目次階層**: 本テンプレートの初期設定では `toc-depth: 2`（章・節まで）を目次対象としています。

### 1.2 読み仮名（ルビ）の記法とワークフロー

Markdownの仕様上、標準構文に含まれない高度なテキスト修飾はインラインHTMLタグとして記述できることが認められています。本テンプレートの組版パイプラインでは、このMarkdown本来のインラインHTML表現を活用してルビ組版を実現しています。

#### 執筆時と組版時の分離設計
執筆者の思考を妨げず可読性を保つため、執筆時と組版処理時で記法を分離する2段階アプローチを推奨しています。

1. **執筆時（人間が書くとき）**:
   - 可読性と入力速度を優先し、自然な **`漢字（かんじ）` の全角かっこ書き** で自由に執筆します。
2. **仕上げ時（AIによる一括整形）**:
   - 原稿推敲時、[prompt.md の「読み仮名のHTMLルビ化」](./prompt.md#読み仮名のhtmlルビ化) プロンプトを適用し、組版用の `<ruby>親文字<rt>ルビ</rt></ruby>` 表現へ一括変換します。
3. **組版時（ビルドエンジンによる自動処理）**:
   - PandocおよびLuaフィルター（`filters/ruby.lua`）が `<ruby>` を解釈し、EPUBおよびLaTeX組版命令（`\ruby{親文字}{ルビ}`）へターゲット別に自動展開します。

- **組版タグの構文制約**: `<rb>` や `<rp>` タグはパーサーの誤動作を防ぐため使用せず、`<ruby>` と `<rt>` のみで構成します。
- **見出し内ルビの挙動**: 見出し（`#` や `##`）内にルビが含まれる場合、PDFのしおり（ブックマーク）および目次でのLaTeXマクロ展開エラー・文字化けを防ぐため、フィルターが自動的にルビを除去し親文字のみを抽出します。

### 1.3 日本語約物および禁則処理仕様
- **行頭禁則**: 句読点（`、` `。`）、閉じカッコ（`」` `）` `｝`）、促音・拗音小文字（`っ` `ゃ` `ゅ` `ょ`）を行頭に配置しない（`jlreq` および `epub.css` で制御）。
- **行末禁則**: 起こしカッコ（`「` `（` `｛`）を行末に配置しない。
- **全角・半角原則**: 本文中の英数字は原則として半角を用い、短い単位・番号は縦中横、長い英単語は90度回転（横倒し）で組版されます。


## 2. 書誌メタデータ仕様（YAML Schemas）

### 2.1 電子書籍用メタデータ (`metadata-epub.yaml`)

PandocがEPUB 3パッケージ文書（`content.opf`）を生成する際に適用するメタデータスキーマです。書籍情報に合わせてユーザーが任意に設定します。

| フィールド | 型 | 必須 | サンプル初期値 | 説明 |
|:---|:---|:---|:---|:---|
| `title` | string | **必須** | `"書籍出版の手引き"` | 書籍の正式タイトル（Dublin Core `dc:title`） |
| `author` | string | **必須** | `"山田太郎"` | 著者名・ペンネーム（Dublin Core `dc:creator`） |
| `language` | string | **必須** | `"ja"` | 言語コード（Dublin Core `dc:language`） |
| `rights` | string | 任意 | `"Copyright (C) 2026..."` | 著作権および利用ライセンス表示 |

### 2.2 ペーパーバック組版メタデータ (`metadata-pdf.yaml`)

LuaLaTeXの日本語組版クラス `jlreq` および `geometry` パッケージに渡される設定スキーマです。
システムの**固定仕様**と、書籍の体裁に合わせてユーザーが自由に調整できる**設定可能パラメータ（サンプル初期設定値）**に分かれています。

#### システム固定仕様
- `documentclass: jlreq`: 電子組版・出版用日本語LaTeX標準ドキュメントクラス
- `classoption`:
  - `tate`: 本文を縦書き（右開き）で組版する必須指定

#### ユーザー設定可能パラメータ（サンプル初期値）
ユーザーは企画する書籍の判型、ページ数、好みのデザインに応じて、以下の値を自由にカスタマイズできます。

| パラメータ | サンプル初期値 | 変更例・カスタマイズの目安 | 技術的意味・組版上の役割 |
|:---|:---|:---|:---|
| `classoption` | | | |
| - `paper` | `a5` | `b6`, `shouroku` 等 | **判型指定**。標準的な書籍・技術書はA5判、文芸・一般書は四六判やB6判などを指定可能。 |
| - `fontsize` | `10.5pt` | `10pt`, `11pt` 等 | **本文フォントサイズ**。級数の大小を用途に合わせて調整。 |
| - `open_bracket_pos` | `gutter` | `zenkakuspace` 等 | 行頭の始め括弧の配置（`gutter` は天付きマス目揃え）。 |
| `toc-depth` | `2` | `1` 〜 `3` | 目次に対象とする深さ（`2` は章と節まで）。 |
| `geometry` | | | **本文余白設定（ペーパーバック印刷用マージン）** |
| - `top` | `20mm` | 15mm 〜 25mm | 天（上部）の余白。 |
| - `bottom` | `20mm` | 15mm 〜 25mm | 地（下部）の余白。 |
| - `inner` | `22mm` | 20mm 〜 30mm | **ノド側（綴じ側）の余白**。ページ数が多い書籍ほどノドの綴じ代を広く確保します。 |
| - `outer` | `18mm` | 15mm 〜 20mm | **小口側（外側）の余白**。 |


## 3. スタイルシート仕様 (`epub.css`)

電子書籍（EPUB）向けスタイルシートは、W3C CSS Writing Modes Level 3に準拠し、Kindle・Apple Books双方での高い表示再現性を担保します。

```css
/* 主要プロパティの仕様 */
html {
  writing-mode: vertical-rl;        /* 縦書き・右開き（ページ送りは右から左） */
  -webkit-writing-mode: vertical-rl;
  font-family: "Noto Serif CJK JP", serif;
}

body {
  margin: 0;
  padding: 0;
  text-align: justify;              /* 両端揃え（行末揃え） */
  text-justify: inter-ideograph;
}

p {
  margin: 0;
  text-indent: 1em;                 /* 段落先頭の1字下げ規則 */
  line-height: 1.8;                 /* 読みやすさを考慮した行送り */
}

ruby {
  ruby-align: center;               /* ルビの親文字中央揃え */
}

rt {
  font-size: 0.5em;                 /* 親文字の半分のサイズ */
}
```


## 4. コンテンツライフサイクル

書籍のコンテンツは以下のパイプラインに沿って段階的に昇華されます。

```mermaid
graph LR
    MEMO["memo.md<br>(未構造化メモ・アイデア)"]
    PROMPT["prompt.md<br>(AI壁打ちプロンプト)"]
    CONTENTS["contents.md<br>(構造化マスター原稿)"]
    DIST["dist/<br>(EPUB/PDFビルド成果物)"]

    MEMO -->|テーマ選定・メモ整理| PROMPT
    PROMPT -->|構造化・推敲・ルビ整形| CONTENTS
    CONTENTS -->|自動組版| DIST
```
