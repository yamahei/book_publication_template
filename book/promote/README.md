# プロモーション動画制作手順書 (book/promote/README.md)

> [!NOTE]
> 書籍宣伝のための、縦書きショート動画を制作するツールです。
> この作業は任意ですが、手間の大きい動画制作を「本文抜粋の選定」と「ブラウザ録画」だけで手軽に完了できるようツールを提供しています。
> 画面解像度や録画エンジンの技術仕様については、[specification.md](./specification.md) を参照してください。


## 4-1. プロモーション動画の制作手順

動画制作は、「どの文章を切り取るか決める（頭を使う）」ステップと、「録画して保存する（機械的作業）」ステップの2段階で進めます。

---

### Step 1: 刺さる本文抜粋の選定（頭を使う決め）

動画は「1本あたり約15秒程度」の短い縦型スクロール動画です。読者の指を止めるキャッチーな文章を選定します。

1. 動画内容の準備
   - [movie_contents.md](./movie_contents.md) に、動画化する書籍本文（[book/contents.md](../contents.md)）を抜粋して貼り付けます。
   - 動画タイトル、背景動画、動画ファイル名も必要です。
2. 動画データへのコンバート
   - [book/prompt.md の「ショート動画定義（movies.js）生成」](../prompt.md#ショート動画定義moviesjs生成) プロンプトに投入し、[recorder/movies.js](./recorder/movies.js)を生成します。
   - ルビは本文同様 `<ruby>親文字<rt>ルビ</rt></ruby>` 形式で自動表示されます。
   - 背景動画やBGMは [background/](./background/) 配下の素材が自動適用されます。


---

### Step 2: 録画と自動保存（機械的作業）

定義ができたら、ブラウザ上で再生しながら録画します。

1. **録画サーバーを起動**:
   ```sh
   # Git Bash または Linux/macOS ターミナルで実行
   ./book/promote/run_server.sh
   ```
2. **ブラウザで録画画面を開く**:
   - Google Chrome または Microsoft Edge で **`http://localhost:8000/recorder/index.html`** を開きます。
3. **録画の実行**:
   - 画面右側のリストから録画したい動画のボタン（例:「動画 01 を録画」）をクリックします。
   - 画面共有ダイアログが表示されるので、**「このタブ（Chromeのタブ / Edgeのタブ）」** を選択して「共有」をクリックします。
   - 自動的にテキストが縦書きスクロール再生され、再生終了後に FastStart 形式のMP4動画として **[book/promote/movie/](./movie/)** 配下へ自動保存されます。
   - 録画済みの動画にはボタンにチェックマーク（✓）が付きます。


---

## 制作完了後の活用

生成された動画（`book/promote/movie/*.mp4`）は、そのまま各SNSプラットフォーム（YouTube Shorts、TikTok、Instagram Reels）へアップロードして、書籍の発売告知やプロモーションにご活用ください。
