# プロモーション動画用抜粋メモ (movie_contents.md)

本ファイルは、**AIに [recorder/movies.js](./recorder/movies.js) を作成させるためのインプット（設計書）**です。
著者が本文（[book/contents.md](../contents.md)）からキャッチーな文章をコピー＆ペーストし、[book/prompt.md の「ショート動画定義（movies.js）生成」](../prompt.md#ショート動画定義moviesjs生成) プロンプトに投入することで、JavaScriptの構文を直接編集することなく `movies.js` を生成できます。

## 2. 動画の抜粋・構成定義

### 動画01: 出版の壁を越える
- **サブタイトル**: 出版の壁を越える
- **ファイル名**: `手引き_出版の壁`
- **背景動画**: `../background/223363_夕日.mp4`

```md
個人が出版を行う際、最大の<ruby>障壁<rt>しょうへき</rt></ruby>となるのが「電子書籍と紙書籍でのフォーマットの違い」です。
ひとつのMarkdownファイルから、高品質なEPUBとPDFを一括生成する。
原稿の<ruby>単一源泉<rt>シングルソース</rt></ruby>化が、あなたの出版活動を劇的に変えます。
```
